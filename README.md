# humanized

Маркетплейс плагинов Claude Code с одним плагином, people-text. Скилл помогает писать и править тексты так, чтобы они читались как написанные человеком: посты, статьи, рабочие письма, резюме. Правила опираются на эссе русской Википедии "Википедия:Признаки сгенерированности текста" (ВП:ПРГЕН).

## Установка

```bash
claude plugin marketplace add roovwhite/humanized
claude plugin install people-text@humanized
```

Скилл лежит в `plugins/people-text/skills/people-text/SKILL.md`.

## Режим проверки, линтер и тесты

Если попросить только проверить текст ("это похоже на нейросеть?", "только проверь", "не правь"), скилл его не переписывает. Он отвечает вердиктом из трёх ступеней (чистый, сомнительный, похоже на сгенерированный) и списком улик, где у каждой короткая цитата и название паттерна из SKILL.md. При обычной правке текст без заметных тэлов возвращается как есть.

Линтер `plugins/people-text/skills/people-text/lint.py` ловит механические нарушения, которые модель пропускает: длинное и среднее тире, ёлочки и фигурные кавычки, utm-метки ChatGPT в ссылках, фразы чат-бота в начале и в конце текста, эмодзи в заголовках и пунктах списков. Он ничего не исправляет, а печатает номер строки, правило и фрагмент и возвращает 1, если что-то нашёл. Нужен только Python 3. Скилл запускает его на исходном тексте и на готовом.

```bash
python3 plugins/people-text/skills/people-text/lint.py draft.md
```

В `plugins/people-text/evals/` лежат 12 сценариев: входной текст и проверки простыми фразами. Как прогнать их вручную, описано в `plugins/people-text/evals/README.md`.

Идея режима проверки, линтера и тестов подсмотрена у [smixs/humanizer-ru](https://github.com/smixs/humanizer-ru).
