# Тестовые сценарии people-text

Каждая папка здесь это один сценарий. В ней лежит входной текст (input.md, в сценарии 09 три файла input-*.md) и checks.md с запросом и проверками. Скрипта-запускатора нет, сценарии гоняются руками.

## Как прогнать сценарий

1. Откройте новую сессию в пустой временной папке, чтобы в контексте не было этого репозитория и прошлых разговоров. Путь к плагину замените на свой.

```bash
cd "$(mktemp -d)" && claude --plugin-dir ~/DEVS/PET/MyTools/humanized/plugins/people-text
```

2. Отправьте запрос из checks.md, а под ним текст из input.md без изменений.
3. Сохраните ответ в out.md рядом со входом. Файлы out*.md в git не попадают.
4. Прогоните линтер на входе и на ответе из корня репозитория.

```bash
python3 plugins/people-text/skills/people-text/lint.py plugins/people-text/evals/01-inflation-triads/out.md
```

5. Пройдите по checks.md построчно и отметьте каждую проверку.

Сценарий 09 состоит из трёх прогонов, по одному на вход, и каждый идёт в новой сессии.

## Что считать провалом

Сценарий провален, если не выполнена хотя бы одна проверка из checks.md. Провалом считается и то, что в проверках не названо: в ответе появились факты, числа или имена, которых не было во входе; изменён код, цитата или текст вне запрошенного куска; линтер на ответе вернул ненулевой код там, где checks.md ждёт 0. Если линтер на входе нашёл не то, что записано в checks.md, сломан вход или линтер, и сценарий нужно сначала починить.
