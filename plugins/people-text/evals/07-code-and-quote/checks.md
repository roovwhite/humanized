# Код и цитата

Запрос: "Поправь текст инструкции" и текст из input.md.

- Блок кода совпадает со входом символ в символ, включая комментарий с длинным тире.
- Строка цитаты со знаком ">" совпадает со входом символ в символ, включая тире и ёлочки внутри неё.
- В прозе убраны "данный", "важно отметить", "Таким образом", "позволяет обеспечить".
- Линтер на входе: код 0, потому что нарушения стоят только в коде и цитате, которые он пропускает.
- Линтер на ответе: код 0.
