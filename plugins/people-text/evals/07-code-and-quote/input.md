Чтобы данный скрипт работал корректно, важно отметить, что необходимо установить переменную окружения.

```bash
export API_URL="https://api.example.com"  # адрес — без слеша в конце
python3 sync.py --dry-run
```

Как написал автор библиотеки в README:

> Флаг --dry-run ничего не пишет в базу — только показывает «план» изменений.

Таким образом, использование флага позволяет обеспечить безопасность процесса синхронизации.
